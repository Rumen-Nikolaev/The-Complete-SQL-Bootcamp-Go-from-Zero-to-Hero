# The Complete SQL Bootcamp: Go from Zero to Hero

Welcome to **The Complete SQL Bootcamp**! This repository contains all the necessary files and exercises to help you learn how to read and write complex queries using SQL, particularly focusing on PostgreSQL. The skills you'll acquire are applicable to other major SQL databases, such as MySQL, Microsoft SQL Server, Amazon Redshift, Oracle, and more.

## Course Sections

1. **Course Introduction**: Overview of the course and what to expect.
2. **SQL Statement Fundamentals**: Introduction to basic SQL statements.
3. **GROUP BY Statements**: Understanding how to group data.
4. **Assessment Test**: Evaluate your knowledge with a test.
5. **JOINS**: Learn how to combine data from multiple tables.
6. **Advanced SQL Commands**: Dive deeper into SQL with advanced commands.
7. **Assessment Test 2**: Another test to assess your progress.
8. **Creating Databases and Tables**: Learn how to create databases and tables.
9. **Assessment Test 3**: Final test to measure your understanding.
10. **Conditional Expressions and Procedures**: Learn about conditional expressions and how to write procedures.

## Repository Files

- **delete.html**: Placeholder files for various sections.
- **General-Challenge1.sql**: SQL challenges for fundamental practice.
- **04:HAVING.sql**: Exercises focused on the HAVING clause.
- **05:JOIN-Challenge-Tasks.sql**: Tasks related to SQL JOINs.
- **06:SubQuery.sql**: Subquery exercises for advanced learning.
- **README.md**: This file, providing an overview of the project.
